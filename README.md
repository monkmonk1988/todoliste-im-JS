# Todo Liste

Eine einfache Todo-Liste im Browser, gebaut mit HTML, CSS und JavaScript.

## Funktionen

- Aufgaben hinzufügen
- Aufgaben abhaken
- Aufgaben löschen

## Live Demo

Teil des Portfolios: [monkmonk1988.github.io](https://monkmonk1988.github.io)

## Starten

`index.html` im Browser öffnen - keine Installation nötig.

## Technologien

- HTML5
- CSS3
- Vanilla JavaScript
